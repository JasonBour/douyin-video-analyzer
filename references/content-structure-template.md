# 内容结构拆解模板（PREP）

本文件定义抖音视频分析中「内容结构」字段的标准输出格式。**目的：看到 PREP 对应的内容，可以直接拿来讲**——所以所有内容都必须是能直接照讲的实质内容，不要写对博主行为的描述（如"他直接给出结论""她强调说""博主在叮嘱"这类）。

## 输出格式

「内容结构」字段按 PREP 四段结构输出：

```
P 观点：<一句话说清视频核心观点，可直接照讲>

R 为什么这么说：<支撑观点的理由，直接给内容本身>
1. <理由1，直接可讲>
2. <理由2，直接可讲>
3. <理由3，直接可讲>

E 展开讲讲：<展开/案例/方法，直接写展开的实质内容，可照讲>

P 结尾总结：<结尾总结，可直接照讲>
```

## 规范要点

1. **P 观点**：一句话核心观点，直接写观点本身，不写"博主认为"。
2. **R 理由**：直接写理由内容。**只有当理由确实是并列的多点时，才用 1、2、3 编号**；如果 R 是一两句连续的话（递进/转折/论证一段话，不是并列罗列），就直接写成一段话，**不要强行拆成编号**。编号只服务于"确实存在多个并列理由"这一种情况。
3. **E 展开**：直接写展开的实质内容（案例经过、方法步骤、数据细节），**禁止写"给出结论并叮嘱""强调这个认知""用案例说明"这类对博主行为/手法的描述**。如果视频就是靠反复强调来展开，就直接把展开的原话写出来。
4. **P 结尾总结**：直接写结尾总结的话，可照讲。
5. **可讲性优先**：写完后自检——这句话能不能直接照着说给别人听？能，才对。任何"作者在做什么"的元描述一律删除。
6. **基于原文**：内容来自逐字稿，保留原文表达，可适当精简连接词，不编造。
7. **允许缺段，禁止凑数**：PREP 是拆解工具不是强制模板，实际视频可能缺某一段（如没有独立案例的 E、没有明确理由的 R）。**某段没有实质内容时，如实标注"（本视频为XX型内容，无独立展开/案例部分）"这类说明，绝不能为了填满 PREP 而把其他段落的内容重复搬进来**。特别警惕 E 和 R 重复——R 是"为什么这么说"的论据，E 是"展开讲讲"的案例/故事/方法/数据，二者本质不同，内容必须互不重复。

## 结构变种判定（PREP / PEP / PR）

PREP 是拆解工具不是强制模板，实际视频可能缺某一段。拆解前先判断这条视频属于哪种结构变种，避免后期分类错误。

**判断流程：先看有没有"为什么"（R），再看有没有"案例/展开"（E）。**

```
Q1 · 视频有没有独立的"为什么这么说"论证段？
   → 没有（主体是并列观点/建议清单）＝ PEP 型，R 标注缺段
Q2 · 有论证段之后，有没有案例/故事/操作展开？
   → 没有 ＝ PR 型，E 标注缺段
   → 有 ＝ PREP 完整型
```

### PREP 完整型（P→R→E→P）
- 既有"为什么"论证，又有案例/方法展开，且 R 与 E 内容不同。
- 示例：曈心理"不要低估1万块的威力"——R=消费vs杠杆思维，E=投资仪表/技能/圈子。

### PEP 无 R 型（P→E→P）
- 主体是**并列观点/建议清单**（如"给你几句话"、"3个方法"、"几点建议"），P 只写引入句，主体并列内容放 E，无独立论证段。
- R 如实标注："（本视频为观点罗列型内容，无独立理由部分）"
- 示例：草根创业者"给你几句话"——P=创业十几年给草根创业者几句话，E=五句话并列，R 缺段。

### PR 无 E 型（P→R→P）
- 纯论证，只有观点+理由，没有独立案例/故事/方法展开。
- E 如实标注："（本视频为观点强调型内容，无独立展开/案例部分）"
- 示例：陈昌文"个人进步"——P+R 论证，无独立 E。

**核心原则**：缺哪段就如实标注哪段，绝不为了填满 PREP 而把别的段落内容搬进来重复。

## 编号使用判断

**用编号**（理由确实是并列罗列的多点）：
```
R 为什么这么说：
1. 不要想着找贵人、不要想着网络上来个大V帮你一下；
2. 不要想着借钱、不要想着有人投资你；
3. 别想其他任何事情，只有个人进步这一条路。
```

**不用编号**（理由是一两句话的连续论证，拆编号反而生硬）：
```
R 为什么这么说：绝大部分普通人每天上班八个小时，下班了以后该玩玩，怎么可能会有突破？只有下班以后再干四个小时，超长期深入思考业务才可能有机会成为主管。在哪个行业里一定要混成行业专家，这才是世界的真相。不存在认知，但存在一个东西叫行业认知。
```

判断标准：把理由逐条念出来，如果彼此是并列的独立点 → 编号；如果本来就是一句话顺下来的逻辑（递进/转折/铺垫）→ 直接写一段。宁可少编号，不要为了"看起来整齐"而强行编号。

## 示例

以下是用"只有个人的进步才是解决一切问题的根源"这条视频做示例（R 与 E 内容重复时，E 如实标注缺段）：

```
P 观点：只有个人的进步才是解决一切问题的根源，也是解决所有问题的最优解。

R 为什么这么说：
1. 不要想着找贵人、不要想着网络上来个大V帮你一下；
2. 不要想着借钱、不要想着有人投资你；
3. 别想其他任何事情，只有个人进步这一条路。

E 展开讲讲：（本视频为观点强调型内容，无独立展开/案例部分）

P 结尾总结：只有个人的进步才能解决一切问题，记住这句话。
```

> ❌ 错误示范 1（写了对博主行为的描述，不可取）：
> E 展开讲讲：直接给出结论并叮嘱"记下来，如果今年20岁，请你记下来"，强调这个认知对年轻人尤其重要。
>
> ❌ 错误示范 2（E 与 R 重复凑数，不可取）：
> E 展开讲讲：只有个人的进步才是解决所有问题的最优解，记下来，如果今年20岁，请你记下来；不要想其他任何事情，不要想着找贵人，不要想着网络上来个大V帮你一下，不要想着借钱，不要想着有人投资你。
>
> ✅ 正确示范（如实标注缺段）：
> E 展开讲讲：（本视频为观点强调型内容，无独立展开/案例部分）
